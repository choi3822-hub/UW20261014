# 일별 심사현황 대시보드 PRD

## 1. 문제점
청약완료 후 심사진행단계별 현황을 실시간으로 파악하기 어렵다.

## 2. 개선목표
심사자분배에서 떨어진 건수와 심사자별 작업화면 내 데이터(상태 변경 이력)를 조합하여
**일별 심사현황(전날 기준, D-1)** 을 확인할 수 있게 한다.

## 3. 핵심지표
| 지표 | 정의 |
| --- | --- |
| 분배건수 | 조회기간 내 심사자분배일자가 속한 건수 (= 전체 건수, 비율의 분모) |
| 심사상태별 건수 / 비율 | 기준일 종료 시점의 상태별 건수, 분배건수 대비 비율 |
| 누적심사건수 | 기준일까지 심사가 종결(승인·조건부승인·거절·철회)된 건수 |
| 진행중 건수 | 분배완료(미착수)·심사중·보완요청 상태 건수 |
| 심사지연건수 | 진행중 건 중 분배일로부터 경과일수가 SLA(기본 3일)를 초과한 건수 |

### 심사상태 정의
| 코드 | 상태명 | 구분 |
| --- | --- | --- |
| ASSIGNED | 분배완료(미착수) | 진행중 |
| IN_REVIEW | 심사중 | 진행중 |
| PENDING_DOCS | 보완요청 | 진행중 |
| APPROVED | 승인 | 종결 |
| CONDITIONAL | 조건부승인 | 종결 |
| DECLINED | 거절 | 종결 |
| WITHDRAWN | 철회/취소 | 종결 |

기준일 시점의 상태는 `상태변경이력` 중 기준일 이전(포함) 마지막 이력으로 산출한다.
따라서 과거 기준일로 조회해도 당시 시점의 현황이 재현된다.

## 4. 데이터 추출
- 조건 검색: 기간(분배일자 From~To) / 채널 / 영업채널 / 심사상태
- 엑셀 다운로드(.xlsx): `요약`, `일별현황`, `심사자별현황`, `상세내역` 시트

## 5. 기대효과
- 전체 건수 대비 심사진행 현황 파악
- 심사지연건수 관리 (지연건 하이라이트 및 지연건만 보기)
